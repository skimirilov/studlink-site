# StudLink

Основной сайт: https://stud-link.ru/

- `/` — лендинг с реквизитами компании.
- `/student/` — демонстрационный кабинет студента.
- `/admin/` — демонстрационный кабинет администратора.

Кабинеты работают без регистрации с тестовыми данными. Изменения сбрасываются при обновлении страницы.

## Разработка

Node.js 22.12+, pnpm 10.32.1.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm preview
```

GitHub Actions собирает `dist/` и публикует сайт при push в `main`.
Домен настроен в GitHub Pages; базовый путь определяется автоматически.
Сборка создаёт страницы маршрутов и `404.html` для динамических ссылок.
